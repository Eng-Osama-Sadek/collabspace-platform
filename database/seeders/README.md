# CollabSpace

A collaborative project management and team workspace platform built with **Laravel**, **Blade**, **Tailwind CSS**, and **MySQL** — designed for multi-track teams (`UI/UX`, `Front End`, and `Back End`) with task tracking, daily updates, meeting transcripts & AI summaries, project wikis, file storage, team messaging, progress reports, notifications, and activity logs.

---

## Key Features

- **Dashboard & Activity Logs:** Real-time workspace overview, key operational metrics, team availability, and a chronological activity log.
- **Projects & Project Wiki:** Create and manage projects (`Alpha`, `SepetGo`, etc.), organize project types, and maintain editable Wiki notes per project.
- **Tasks & Kanban Workflow:** Track tasks across statuses (`todo`, `in_progress`, `in_review`, `completed`), priorities, tracks, assignees, and completion progress.
- **Daily Status Updates:** Structured daily team check-ins covering work completed today, planned next steps, and blockers.
- **Meetings, Transcripts & AI Summaries:** View scheduled meetings, full session transcripts, key takeaways, and generate AI summaries.
- **Files, Chats, Reports & Notifications:** Upload and manage project files, collaborate via public channels and direct chats, submit progress reports, track notifications, and inspect member profiles.

---

## Tech Stack

- **Backend:** PHP, Laravel Framework, Eloquent ORM, Seeders & Migrations
- **Frontend:** Blade Templates, Tailwind CSS
- **Database:** MySQL
- **Tooling:** Git, GitHub, PowerShell
